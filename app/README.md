# go_chat — Flutter client

Демо-клиент для [бэкенда](../backend/README.md).

```
lib/
  config.dart            адрес API (--dart-define=API_URL=...)
  data/                  REST-клиент, WebSocket с переподключением, хранение токена (Keychain/Keystore)
  state/                 контроллеры на ChangeNotifier: сессия, список диалогов, чат
  ui/                    экраны и виджеты
```

- Время сообщений приходит с сервера в UTC и показывается в локальном часовом поясе.
- Сообщение сначала показывается как «отправляется» (🕓), подтверждается эхом `message.new`
  по `client_id`. Без сети оно остаётся в очереди и уходит после переподключения
  (сервер дедуплицирует повторы).
- «Печатает…» отправляется не чаще раза в 3 c и гаснет у собеседника через 6 c без обновлений.
- Прочтение отправляется, только когда чат открыт и приложение на переднем плане.
- Cleartext HTTP разрешён только для локальных адресов разработки; в остальных случаях нужен TLS.
